❓ API Keys, Telemetry & Application Truth

Clear, direct answers for you and your manager regarding how data flows and what exists.

Q1: Do we need an external API key to run this project?
NO. Absolutely zero external API keys are required.
The application is completely self-contained. It runs locally using:
  • Local State Store (src/lib/chetak/store.tsx): Uses React Context and browser storage to manage tickets, status updates, and notes.
  • Built-in Seed Data (src/lib/chetak/data.ts): Pre-populated with realistic Bajaj Chetak EV models, customer records, VINs, battery numbers, and service history.
  • No Cloud Subscriptions: You don't need OpenAI, Google Maps, AWS IoT, or any paid service to demo the app.
Q2: Why did the earlier pictures show a 48-cell grid matrix?
The neon 48-cell diagram was an illustrative design mockup (a concept visual of how an enterprise IoT dashboard could look).
In the real application, the vehicle telemetry is displayed cleanly in the Vehicle & Dealer Context Card:
  • Cell Voltage Summary: Displays min-to-max cell voltage range (e.g. 12 V – 14 V).
  • ECU List: Badges showing MCU-v2.1, BMS-v1.4, VCU-v3.0.
  • Hardware IDs: Exact VIN number, battery pack ID, and scooter model render.
Q3: How would live hardware telemetry connect in production?
If your client or manager wants live streaming telemetry directly from the scooter while on the road, that is an IoT Phase 2 extension:

A physical 4G telematics dongle in the scooter sends CAN-bus data over MQTT into an IoT Gateway (AWS IoT Core or Azure IoT Hub), which writes into this service desk's ticket table. The schema (minCellVoltage, maxCellVoltage, ecuList) is already designed and ready in the code!

Why This Application Matters

EV hotline support is fundamentally different from petrol vehicle support. When a customer calls with a power loss, it could be cell imbalance, motor controller heat, or software logic.

  • Zero Ambiguity: Executives see the exact VIN, battery serial, and voltage range immediately.
  • Faster Triage: Eliminates 15-minute phone calls asking customers for serial numbers.
  • Audit Compliance: Every status change, note, and resolution step is logged.
